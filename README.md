A 4,092-byte deterministic Python chess engine featuring hybrid asymmetric PeSTO evaluation, pawn hash table (passed/doubled/isolated pawns), king pawn shield, endgame mop-up, Zobrist TT, PVS, NMP, RFP, IIR, FP/LMP, check-aware LMR, killers, history gravity/malus, and MVV-LVA quiescence search.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 -P -s main.py
```
