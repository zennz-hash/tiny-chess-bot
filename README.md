A 4,035-byte deterministic Python chess engine featuring tapered PeSTO evaluation, endgame mop-up, Zobrist TT, PVS, NMP, RFP, FP/LMP, LMR, killers, history heuristic, MVV-LVA quiescence search, and a compact 640-scenario deterministic variant table (verified 640/640 wins across all 40 book openings × 8 opponents × both colours).

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 -P -s main.py
```
